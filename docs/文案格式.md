# ASO 文案 md 格式

每种语言写一个 md 文件，在「商店文案」页点「文件」，把这些文件一次全选，就能一起导入。

## 规则

1. **语言**：写在文件开头的 `locale:` 里，用 App Store Connect 的语言代码：`zh-Hans` `zh-Hant` `en-US` `ja` `ko` `de-DE` `fr-FR` `es-ES` `pt-BR` `it` `ru` `tr` `th` `vi` `id` `ms`。没写 `locale` 时，从文件名末尾识别，比如 `aso-en-US.md`、`metadata-ja.md`、`xxx-zh.md`。
2. **字段**：每个字段是一个 `##` 标题。内容就是标题下面、到下一个 `##` 之前的全部文字，会原样导入，所以可以有多段。
3. **标题名称**：标题用下表里的名字，英文中文都行，大小写随意，末尾带的括号说明（比如 `(≤30 chars)`）会被忽略。
4. **其他内容会忽略**：认不出的 `##` 段落（品牌、分类、备注等）会被跳过，可以放心留在文件里；`###` 不算新段落，会被当成内容。
5. **只覆盖写了的字段**：没写的字段保持工具里原来的内容。空标题也会被跳过。
6. **审核信息**：`App Review` 和 `Review Notes` 所有语言共用，只在一个文件里写就行。

| 标题 | 也认 | 上限 |
|---|---|---|
| `Name` | 名称、App Name、Title | 30 |
| `Subtitle` | 副标题 | 30 |
| `Keywords` | 关键词 | 100，英文逗号分隔（换行和中文逗号会自动转成英文逗号） |
| `Promotional Text` | 推广文本 | 170 |
| `Description` | 描述 | 4000 |
| `What's New` | 此版本新增内容、更新说明、Release Notes | 4000 |
| `Privacy Policy URL` | 隐私政策网址 | |
| `Support URL` | 技术支持网址 | |
| `Marketing URL` | 营销网址 | |
| `App Review` | 审核信息、Review Contact | 每行一个 `键: 值`，见下面的示例 |
| `Review Notes` | 审核备注 | 4000 |

开头还可以写 `app_id:` 和 `version:`，导入时会一起填进「App 信息」。

Description 和 What's New 是纯文本，App Store 不渲染 Markdown，`**粗体**` 会原样显示出来。分点请用 `•`。

## 示例：aso-en-US.md

```markdown
---
locale: en-US
---

## Name
Locato - Family Locator

## Subtitle
Share Location with Family

## Keywords
gps,tracker,find,phone,friends,safety,geofence,sos,kids,share

## Promotional Text
See your family on the map in real time. Get arrival alerts and send SOS in one tap.

## Description
Locato keeps the people you love close, no matter the distance.

KEY FEATURES
• Live Location — See where your family is, anytime
• Arrival & Leave Alerts — Know when they reach school or home

## What's New
• Faster map loading
• Bug fixes

## Privacy Policy URL
https://example.com/privacy

## Support URL
https://example.com/support

## Marketing URL
https://example.com

## App Review
- First Name: San
- Last Name: Zhang
- Phone: +86 13800000000
- Email: review@example.com
- Demo Account: demo@example.com
- Demo Password: 123456

## Review Notes
Location permission is required to show the map.
```

## 让 AI 帮你改

在「商店文案 → 一键导入」的提示里点「md 格式」，会复制一段完整的格式说明。把它连同你的旧文件一起发给 AI，就能拿到改好的文件。
